UsageTracker 0.1.10 improves Claude account setup and session launching, usage accuracy, and automatic recovery.

## Highlights

- Sign in to Claude by pasting an authentication code, and configure each account's working directory, model, effort, and launch flags before opening a session.
- Import local Claude preferences, project trust, and prompt history into isolated accounts while preserving their identity and MCP configuration.
- See account plan labels, clearer remaining allowance and notification wording, and more consistent model metrics.
- Include archived Codex sessions in usage history, with improved account attribution, token accounting, and pricing.
- Recover usage more reliably after wake and distinguish stale data or collection failures from quota status.
- Improve Claude usage collection with a profile-isolated terminal fallback and more reliable credential synchronization.
- Recover Keychain permissions explicitly per account without background authorization prompts, and strengthen installer signature verification.

## Installation

The UsageTracker menu bar app requires macOS 14 or newer.

```sh
curl --proto '=https' --tlsv1.2 -fsSL \
  https://github.com/joeymalvinni/usagetracker/releases/latest/download/install.sh | bash
```

The installer verifies published SHA-256 checksums, archive contents, and ad-hoc code-signature integrity. By default it installs:

- `UsageTracker.app` in `~/Applications`
- `usage` in `~/.local/bin`

> [!IMPORTANT]
> This release is ad-hoc signed and is **not notarized by Apple**. macOS may require you to approve UsageTracker manually the first time it opens. Follow the [Open Anyway instructions](https://github.com/joeymalvinni/usagetracker/blob/v0.1.10/docs/troubleshooting.md#opening-the-unnotarized-app) without disabling Gatekeeper globally.
